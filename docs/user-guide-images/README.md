# قائمة صور دليل الاستخدام

لا توجد صور فعلية في هذه الدفعة؛ المواضع في الدليل مقصودة حتى يلتقط فريق التشغيل لقطات من بيئة آمنة بعد إخفاء البيانات الحساسة.

| اسم ملف الصورة | الصفحة أو الرابط | الدور المطلوب | العناصر التي يجب أن تظهر | بيانات يجب إخفاؤها |
|---|---|---|---|---|
| `enrollment-import.png` | `/admin/manara-enrollment-import` | admin أو super-admin | رفع Excel والملخص | أسماء الطلاب وأرقامهم واسم الملف الحقيقي |
| `schedule-import-issues.png` | `/admin/schedule-import-issues` | مستخدم مخول بالمعالجة | الفلاتر والمشكلات والإجراءات | أسماء المدرسين والطلاب والدفعات |
| `lecture-sessions.png` | `/admin/lecture-sessions` | مستخدم مخول | التبويبات والعدادات وزر التحديث | أسماء الطلاب ورموز QR وOTP |
| `current-academic-term.png` | `/admin/current-academic-term` | مستخدم يملك إدارة الفصول | التفعيل وتواريخ التدريس | أسماء أو بيانات تشغيلية غير مناسبة للنشر |
| `lecturer-account-preparation.png` | `/admin/lecturer-account-preparation` | admin أو super-admin | حالة الحساب وزر التهيئة | أسماء الدخول وكلمات المرور وملف الاعتماد |
| `my-profile.png` | `/admin/my-profile` | أي مستخدم مخول | الاسم واسم المستخدم وقسم كلمة المرور | كلمة المرور وPIN وأي بيانات شخصية |
